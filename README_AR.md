# نشر FitLife
1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. اربط المستودع مع Vercel وانشره.
3. في Vercel افتح Settings ثم Environment Variables وأضف OPENAI_API_KEY بمفتاح API جديد وسري.
4. إذا ظهر خطأ model not found، أضف OPENAI_MODEL باسم نموذج متاح في حساب API.
5. افتح التطبيق وأدخل رابط مشروع Vercel في الإعدادات.

مهم: لا تضع مفتاح API في HTML أو ترسله لأي شخص. استخدام OpenAI API قد يتطلب فوترة منفصلة عن اشتراك ChatGPT. تحليل الطعام من الصورة تقديري وليس قياساً دقيقاً للوزن أو الزيت.
